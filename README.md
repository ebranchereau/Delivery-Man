To run/test/use: 
```R
R

```

Or open ```runTestDM.R``` in RStudio and click ```CTRL + SHIFT + S``` to run the test  
Or open ```runDeliveryMan.R``` in RStudio and click ```CTRL + SHIFT + S``` to run the simulation
